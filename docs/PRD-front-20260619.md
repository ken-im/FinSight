# FinanceDataInsight Dashboard App

## 1. 프로젝트 개요
- 프로젝트명: FinanceDataInsight Frontend
- 프로젝트목적: 시장의 금융데이터(지수, 주가 등등)를 분석하고 시각화하여 사용자에게 직관적이고 편리하게 제공

## 2. 개발 범위
- 서비스할 금융데이터에 대한 정의 및 데이터 원천 등을 관리하는 관리자 화면
- 수집된 금융데이터를 분석/가공하고 시각화해서 제공하는 화면
- 완료된 프로그램: 금융데이터 수집 및 저장하는 백엔드 프로그램 - docs/PRD-20260323.md, PLAN-backend-20260617.md

## 3. 아키텍처 개요

### 3.1. 배포 플랫폼 (모두 무료 티어)
| 구성 요소 | 플랫폼 | 비고 | 구분 |
| --- | --- | --- | --- |
| 데이터 수집 | GitHub Actions | 스케줄(cron) 기반 Python 스크립트 자동 실행 | 완료 |
| 데이터 저장 | Neon DB (Serverless PostgreSQL) | 상시 가동 서버리스 DB, 시계열 데이터 누적 | 완료 |
| 데이터 시각화 | Streamlit Community Cloud | 대시보드 웹앱 호스팅 | 진행 |

### 3.2. 전체 구조
1. **데이터 수집 (GitHub Actions)**: 매일 정해진 시간(예: 오전 8시)에 Python 스크립트를 자동 실행하여 주가 API(Yahoo Finance 등)에서 데이터를 가져온 뒤 Neon DB에 적재합니다.
2. **데이터 저장 (Neon DB)**: 상시 가동되는 서버리스 PostgreSQL로, 주가 시계열 데이터를 누적 보관합니다.
3. **데이터 시각화 (Streamlit)**: 사용자가 대시보드에 접속하면 Neon DB에서 데이터를 읽어와 Plotly로 인터랙티브 차트를 렌더링합니다.

```
GitHub Actions ──(수집/적재)──▶ Neon DB ──(조회)──▶ Streamlit Dashboard ──▶ 사용자
  (매일 스케줄)                (PostgreSQL)           (Plotly 시각화)
```

- 데이터 원천: FinanceDataReader 및 야후파이낸스(yfinance)
- 데이터 처리: Python 3.x (Pandas, NumPy)
- 향후 저장된 데이터를 분석하여 추가 시각화·분석 자료를 지속적으로 확장 가능

## 7. 관리자 화면 요구 사항

### 7.1) 종목마스터 관리
- 대상 테이블: symbol_master
- 종목 전체 목록을 보여주고, row를 선택하면 해당 종목의 정보를 화면 하단의 입력 화면에 바인딩
- symbol_id, source, symbol, symbol_nm 항목으로 필터링 가능
- 입력 화면에서는 각 항목의 내용을 수정할 수 있으며, [신규|수정|삭제] 버튼을 선택할 수 있음
- [신규] 버튼 클릭: 입력 화면의 내용으로 새로운 종목이 종목마스터에 등록 - symbol_id 신규 채번. 단, 기존 sourec + symbol과 중복인 경우는 저장 불가
- [수정] 버튼 클릭: 입력 화면의 내용으로 종목마스터 업데이트. 단, 기존 sourec + symbol과 중복인 경우는 저장 불가
- [삭제] 버튼 클릭: 선택된 row의 symbol_id 종목을 DB에서 삭제. 단, 삭제 전에 사용자에게 삭제 여부를 한번 더 확인

### 7.2) 종목종가내역 관리
- 대상 테이블: daily_price
- 종목마스터 목록에서 선택한 row의 symbol_id에 대한 종가내역을 일자 DESC 순으로 조회 - 한 페이지당 30 row씩 보여주기.
