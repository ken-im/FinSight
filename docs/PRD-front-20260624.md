## 1. 프로젝트 개요
- 기존 PRD-front-20260619.md에 이어지는 확장판


## 2. 개발 범위
- 기 완료된 Dashboard 메뉴를 개편하고 분석 기능을 추가


## 3. 메뉴 개편

### 3.1 기존 메뉴(좌측 패널)는 아래와 같이 개편
1) app --> 시장지표트랜드 (Home 화면)
2) admin symbols --> 매뉴에서 제거
3) admin prices --> 매뉴에서 제거
4) 이동평균분석 : 신규 메뉴 추가
5) 종가내역 조회 --> 시장지표일별시세 : 일반 화면으로 전환
6) 종목마스터 관리 --> Admin Symbols : 관리자 화면 유지, 좌측 패널 가장 아래에 위치

### 3.2 개편 메뉴별 조회 조건
1) 시장지표트랜드 : 현재의 조회 조건 유지
2) 이동평균분석 : 시장지표 선택은 1개만 가능, 기간 설정은 시장지표트랜드와 동일, 이동평균선 3개에 대한 설정값 선택 [1개월|3개월|6개월|1년|2년|3년] default=3개월,1년,3년
3) 시장지표일별시세 : 시장지표 선택은 1개만 가능, 기간 설정은 시장지표트랜드와 동일

### 3.3 이동평균분석 (신규 화면)
1) 환율 추세 분석
   - 통화별 환율 시계열 그래프 제공
   - 기간 내 최고/최저 환율 표시
2) 이동평균 분석
   - 3개월 이동평균: 60일간의 환율 평균, 표시기호=MA3M
   - 1년 이동평균: 250일간의 환율 평균, 표시기호=MA1Y
   - 3년 이동평균: 750일간의 환율 평균, 표시기호=MA3Y
3) 이동평균 계산 방식
   - 단순 이동평균(Simple Moving Average, SMA)
   - SMA(n) = n일간 환율 평균
4) 기본 그래프
   - X축: 날짜(Date), 년도 및 분기(보조선) 간격 표시(예시: 2025-2Q)
   - Y축: 환율
   - 환율 원본 데이터 + 이동평균선 중첩 표시
   - 선택 기간 기준 최고점 일자, 최저점 일자 및 최근 일자의 원본 환율 값을 표시
   - 현재 일자의 원본 환율 값은 수직선 추가하여 강조
5) 그래프 시작 시점의 이동평균 산출을 위하여 충분한 환율 데이터를 가져와서 시각화 한다.
6) 그래프 스타일 및 이동평균 산출과 관련한 내용은 reference/fx_trend 참조.


## 4. 기타 요구 사항
- 지표데이터 보유현황에 refresh 버튼(아이콘 또는 이모지) 추가하여 보유현황 및 시장지표 선택 드롭다운의 내용을 갱신할 수 있도록 한다.
