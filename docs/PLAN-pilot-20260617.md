# FinSight 파일럿 실행 계획 (PLAN-pilot-20260617)

> 본 문서는 [PRD-20260323](./PRD-20260323.md) 전체 아키텍처 중 **데이터 수집 → 저장** 구간을 최소 범위로 검증하기 위한 파일럿 계획이다. 시각화(Streamlit)와 자동화(GitHub Actions)는 파일럿 범위에서 제외한다.

## 1. 파일럿 목표
- 단일 종목 **KS200 (KOSPI 200)** 의 최근 10년치 일별 종가 데이터를 수집한다.
- 종목마스터 / 종목종가내역 2개 테이블을 모델링한다.
- 수집한 데이터를 **Neon DB(PostgreSQL)** 에 정상적으로 적재한다.
- 이후 단계(스케줄 수집·시각화)로 확장 가능한 코드 구조와 DB 스키마를 확보한다.

## 2. 파일럿 범위

### 2.1. 포함 (In Scope)
| 항목 | 내용 |
| --- | --- |
| 대상 데이터 | KS200 (KOSPI 200), 최근 10년 (수집 실행일 기준 -10년 ~ 당일) |
| 데이터 원천 | FinanceDataReader(`FDR`) — `fdr.DataReader('KS200', start, end)` |
| 저장소 | Neon DB (Serverless PostgreSQL) |
| 기능 | 종목마스터 등록, 종가내역 수집·적재(멱등 upsert) |

> **용어**: 지수 / 국내·해외 종목 / 암호화폐 등을 포괄하기 위해 `ticker` 대신 **`symbol`** 용어로 통일한다.

### 2.2. 제외 (Out of Scope)
- Streamlit 대시보드 / 시각화
- GitHub Actions 자동 스케줄링
- 다중 종목 / 해외·암호화폐 종목 수집
- 관리자 화면

## 3. 데이터 모델링

### 3.1. 종목마스터 (`symbol_master`)
| 컬럼 | 타입 | 제약 | 설명 |
| --- | --- | --- | --- |
| `symbol_id` | BIGINT (IDENTITY) | PK | 종목 식별자 (시퀀스 자동 채번) |
| `source` | VARCHAR(20) | NOT NULL | 데이터 원천 (예: `FDR`, `YAHOO`) |
| `symbol` | VARCHAR(30) | NOT NULL | 종목/지수/코인 코드 (예: `KS200`) |
| `symbol_nm` | VARCHAR(100) | NOT NULL | 명칭 (예: `KOSPI 200`) |
| `remark` | VARCHAR(255) | NULL | 비고 (설명, 분류 등) |
| `created_at` | TIMESTAMPTZ | NOT NULL, default now() | 등록 일시 |
| `updated_at` | TIMESTAMPTZ | NOT NULL, default now() | 수정 일시 |

- **기본키**: `symbol_id` (시퀀스) → 원천에 따라 동일 `symbol` 코드가 중첩될 수 있으므로 대리키(surrogate key) 사용
- **유니크 제약**: (`source`, `symbol`) → 동일 원천 내 동일 코드 중복 등록 방지
- `source` 컬럼으로 추후 자동화 시 **데이터 원천별 수집 분기**가 가능하도록 설계

### 3.2. 종목종가내역 (`daily_price`)
| 컬럼 | 타입 | 제약 | 설명 |
| --- | --- | --- | --- |
| `symbol_id` | BIGINT | PK, FK → `symbol_master.symbol_id` | 종목 식별자 |
| `trade_dt` | VARCHAR(8) | PK | 일자 (`YYYYMMDD`) |
| `close_price` | NUMERIC(18,4) | NOT NULL | 종가(지수) |
| `open_price` | NUMERIC(18,4) | NULL | 시가 |
| `high_price` | NUMERIC(18,4) | NULL | 고가 |
| `low_price` | NUMERIC(18,4) | NULL | 저가 |
| `volume` | BIGINT | NULL | 거래량 |
| `trade_amount` | NUMERIC(20,2) | NULL | 거래금액 |
| `change_rate` | NUMERIC(10,6) | NULL | 전일 대비 등락률 |
| `created_at` | TIMESTAMPTZ | NOT NULL, default now() | 적재 일시 |

- **복합 기본키**: (`symbol_id`, `trade_dt`) → 동일 일자 중복 적재 방지 및 upsert 키로 사용
- 인덱스: `idx_daily_price_symbol_date (symbol_id, trade_dt DESC)` (조회 성능용)
- `trade_dt` 는 `YYYYMMDD` 형식 문자열(VARCHAR(8))로 저장
- 참고: 지수 데이터 특성상 `volume` / `trade_amount` 등 일부 컬럼은 원천에서 제공되지 않을 수 있으므로 NULL 허용으로 설계

### 3.3. DDL (참고)

CREATE TABLE symbol_master (

    remark      VARCHAR(255),

COMMENT ON TABLE  symbol_master            IS '종목마스터 (지수/국내·해외 종목/암호화폐 등 종목 정의)';
COMMENT ON COLUMN symbol_master.symbol_id  IS '종목 식별자 (시퀀스 자동 채번, PK)';
COMMENT ON COLUMN symbol_master.source     IS '데이터 원천 (예: FDR, YAHOO)';
COMMENT ON COLUMN symbol_master.symbol     IS '종목/지수/코인 코드 (예: KS200)';
COMMENT ON COLUMN symbol_master.symbol_nm  IS '종목 명칭 (예: KOSPI 200)';
COMMENT ON COLUMN symbol_master.remark     IS '비고 (설명, 분류 등)';
COMMENT ON COLUMN symbol_master.created_at IS '등록 일시';
COMMENT ON COLUMN symbol_master.updated_at IS '수정 일시';

CREATE TABLE daily_price (

COMMENT ON COLUMN daily_price.trade_dt     IS '거래 일자 (YYYYMMDD)';
COMMENT ON COLUMN daily_price.close_price  IS '종가(지수)';
COMMENT ON COLUMN daily_price.open_price   IS '시가';
COMMENT ON COLUMN daily_price.high_price   IS '고가';
COMMENT ON COLUMN daily_price.low_price    IS '저가';
COMMENT ON COLUMN daily_price.volume       IS '거래량';
COMMENT ON COLUMN daily_price.trade_amount IS '거래금액';
COMMENT ON COLUMN daily_price.change_rate  IS '전일 대비 등락률';

### 3.4. SQLAlchemy 2.x ORM 모델 (참고)
```python
from datetime import datetime
from decimal import Decimal
from sqlalchemy import (
    String, Numeric, BigInteger, ForeignKey, UniqueConstraint, func,
)
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column


class Base(DeclarativeBase):
    pass


class SymbolMaster(Base):
    __tablename__ = "symbol_master"
    __table_args__ = (
        UniqueConstraint("source", "symbol", name="uq_symbol_master_source_symbol"),
        {"comment": "종목마스터 (지수/국내·해외 종목/암호화폐 등 종목 정의)"},
    )

    symbol_id: Mapped[int] = mapped_column(
        BigInteger, primary_key=True, autoincrement=True,
        comment="종목 식별자 (시퀀스 자동 채번, PK)",
    )
    source: Mapped[str] = mapped_column(String(20), comment="데이터 원천 (예: FDR, YAHOO)")
    symbol: Mapped[str] = mapped_column(String(30), comment="종목/지수/코인 코드 (예: KS200)")
    symbol_nm: Mapped[str] = mapped_column(String(100), comment="종목 명칭 (예: KOSPI 200)")
    remark: Mapped[str | None] = mapped_column(String(255), comment="비고 (설명, 분류 등)")
    created_at: Mapped[datetime] = mapped_column(server_default=func.now(), comment="등록 일시")
    updated_at: Mapped[datetime] = mapped_column(
        server_default=func.now(), onupdate=func.now(), comment="수정 일시",
    )


class DailyPrice(Base):
    __tablename__ = "daily_price"
    __table_args__ = ({"comment": "종목종가내역 (일별 시세 시계열)"},)

    symbol_id: Mapped[int] = mapped_column(
        BigInteger, ForeignKey("symbol_master.symbol_id"), primary_key=True,
        comment="종목 식별자 (FK → symbol_master.symbol_id)",
    )
    trade_dt: Mapped[str] = mapped_column(String(8), primary_key=True, comment="거래 일자 (YYYYMMDD)")
    close_price: Mapped[Decimal] = mapped_column(Numeric(18, 4), comment="종가(지수)")
    open_price: Mapped[Decimal | None] = mapped_column(Numeric(18, 4), comment="시가")
    high_price: Mapped[Decimal | None] = mapped_column(Numeric(18, 4), comment="고가")
    low_price: Mapped[Decimal | None] = mapped_column(Numeric(18, 4), comment="저가")
    volume: Mapped[int | None] = mapped_column(BigInteger, comment="거래량")
    trade_amount: Mapped[Decimal | None] = mapped_column(Numeric(20, 2), comment="거래금액")
    change_rate: Mapped[Decimal | None] = mapped_column(Numeric(10, 6), comment="전일 대비 등락률")
    created_at: Mapped[datetime] = mapped_column(server_default=func.now(), comment="적재 일시")
```

## 5. 단계별 실행 계획

- [ ] **uv 설치** 후 프로젝트 초기화 및 의존성 설치 (Python 3.12)

uv 환경 구성 (파일럿 최소):
```bash
# uv 설치 (미설치 시)
# Windows(PowerShell): powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

uv init --python 3.12             # pyproject.toml / .python-version 생성
uv add FinanceDataReader pandas "SQLAlchemy>=2.0" "psycopg[binary]" python-dotenv
uv run python -m src.init_db      # 가상환경(.venv) 자동 사용하여 실행
```

- `uv add` 실행 시 `.venv` 가상환경과 `uv.lock` 잠금 파일이 자동 생성/갱신된다.
- 스크립트는 `uv run <command>` 형태로 실행하여 가상환경 활성화 단계를 생략한다.
- Streamlit Cloud 등 배포 호환을 위해 `requirements.txt` 가 필요하면 다음으로 생성:
```bash
uv export --no-hashes -o requirements.txt
```

## 7. 리스크 및 고려사항
| 항목 | 내용 | 대응 |
| --- | --- | --- |
| 원천 데이터 컬럼 편차 | 지수 데이터는 거래량/거래금액이 비어있을 수 있음 | 해당 컬럼 NULL 허용, 방어적 매핑 |
| Neon 무료 티어 제한 | 일정 시간 미사용 시 콜드 스타트, 스토리지/연결 제한 | 재시도 로직, 커넥션 풀 최소화 |
| 휴장일/결측 일자 | 영업일만 데이터 존재 | 날짜 연속성 가정하지 않고 원천 기준 적재 |
| 비밀정보 노출 | 연결 문자열 유출 위험 | `.env` gitignore, `.env.example` 만 커밋 |
