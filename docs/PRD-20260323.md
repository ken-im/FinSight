# FinanceDataInsight App

## 1. 프로젝트 개요
- 프로젝트명: FinanceDataInsight
- 프로젝트목적: 시장의 금융데이터(지수, 주가 등등)를 수집하고 시각화하여 사용자에게 직관적이고 편리하게 제공

## 2. 개발 범위
- 서비스할 금융데이터에 대한 정의 및 데이터 원천 등을 관리하는 관리자 화면
- 금융데이터 수집 및 저장하는 백엔드 프로그램
- 수집된 금융데이터를 시각화해서 제공하는 화면

### 3. 아키텍처 개요
- 데이터베이스: PostgreSQL
- 데이터 원천: FinanceDataReader 및 야후파이낸스(yfinance)
- 데이터 처리: Python 3.x (Pandas, NumPy)
- 시각화: Plotly.js (프런트엔드)
- 서비스 형태: Web Dashboard (SPA + REST API)

## 4. 기술 스택

### 4.1. 백엔드 (Python)
| 분류 | 기술 | 비고 |
|------|------|------|
| 언어 | Python 3.12 | |
| 웹 프레임워크 | FastAPI | 비동기 REST API, 자동 문서화(Swagger) |
| ORM | SQLAlchemy 2.x | 비동기 지원 |
| DB 마이그레이션 | Alembic | 스키마 버전 관리 |
| 데이터베이스 | PostgreSQL 16 | 시계열 데이터 저장 |
| 데이터 수집 | FinanceDataReader, yfinance | 국내/해외 금융데이터 |
| 데이터 처리 | Pandas, NumPy | |
| 스케줄러 | APScheduler | 주기적 데이터 수집 자동화 |
| 패키지 관리 | Poetry | 의존성 및 가상환경 관리 |

### 4.3. 인프라 / 개발 환경

## 5. 기본 사항
- 프런트엔드와 백엔드를 분리하여 개발 (프런트: 3000, 백엔드: 8000 포트)
- 백엔드를 Python 단일 언어로 통일하여 데이터 수집·처리·API를 일관성 있게 관리
- 개인적인 프로젝트
