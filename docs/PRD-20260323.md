# FinanceDataInsight App

## 1. 프로젝트 개요
- 프로젝트명: FinanceDataInsight
- 프로젝트목적: 시장의 금융데이터(지수, 주가 등등)를 수집하고 시각화하여 사용자에게 직관적이고 편리하게 제공

## 2. 개발 범위
- 서비스할 금융데이터에 대한 정의 및 데이터 원천 등을 관리하는 관리자 화면
- 금융데이터 수집 및 저장하는 백엔드 프로그램
- 수집된 금융데이터를 시각화해서 제공하는 화면

## 3. 아키텍처 개요

### 3.1. 배포 플랫폼 (모두 무료 티어)
| 구성 요소 | 플랫폼 | 비고 |
| --- | --- | --- |
| 데이터 수집 | GitHub Actions | 스케줄(cron) 기반 Python 스크립트 자동 실행 |
| 데이터 저장 | Neon DB (Serverless PostgreSQL) | 상시 가동 서버리스 DB, 시계열 데이터 누적 |
| 데이터 시각화 | Streamlit Community Cloud | 대시보드 웹앱 호스팅 |

### 3.2. 전체 구조
1. **데이터 수집 (GitHub Actions)**: 매일 정해진 시간(예: 오전 8시)에 Python 스크립트를 자동 실행하여 주가 API(Yahoo Finance 등)에서 데이터를 가져온 뒤 Neon DB에 적재합니다.
2. **데이터 저장 (Neon DB)**: 상시 가동되는 서버리스 PostgreSQL로, 주가 시계열 데이터를 누적 보관합니다.
3. **데이터 시각화 (Streamlit)**: 사용자가 대시보드에 접속하면 Neon DB에서 데이터를 읽어와 Plotly로 인터랙티브 차트를 렌더링합니다.

```
GitHub Actions ──(수집/적재)──▶ Neon DB ──(조회)──▶ Streamlit Dashboard ──▶ 사용자
  (매일 스케줄)                (PostgreSQL)           (Plotly 시각화)
```

- 데이터 원천: FinanceDataReader 및 야후파이낸스(yfinance)
- 데이터 처리: Python 3.x (Pandas, NumPy)
- 향후 저장된 데이터를 분석하여 추가 시각화·분석 자료를 지속적으로 확장 가능

## 4. 기술 스택
| 분류 | 기술 | 비고 |
| --- | --- | --- |
| 언어 | Python 3.12 | 수집·처리·시각화 단일 언어 |
| 데이터 수집 | FinanceDataReader, yfinance | 국내/해외 금융데이터 |
| 데이터 처리 | Pandas, NumPy | |
| 데이터베이스 | Neon (PostgreSQL 16) | 서버리스, 시계열 데이터 저장 |
| DB 접근 | SQLAlchemy 2.x, psycopg | ORM 및 드라이버 |
| DB 마이그레이션 | Alembic | 스키마 버전 관리 |
| 자동화/스케줄 | GitHub Actions (cron) | 정기 수집 워크플로 |
| 대시보드/시각화 | Streamlit + Plotly | 웹 UI 및 인터랙티브 차트 |
| 패키지 관리 | pip + requirements.txt | Streamlit Cloud 배포 호환 |
| 버전 관리 | Git / GitHub | |

## 5. 기본 사항
- 데이터 수집·처리·시각화를 Python 단일 언어로 통일하여 일관성 있게 관리
- 별도 서버 운영 없이 무료 관리형 서비스(GitHub Actions, Neon, Streamlit Cloud)로 구성
- 개인적인 프로젝트
